Quick Help

My payment was completed, but I cannot see my download.

Return to the project page in the same browser you used for payment and allow a moment for the secure download to appear. If it still does not appear, send us a message below and mention which project you purchased.

I received the wrong PDF or the file will not open.

Tell us which project you purchased and what went wrong. We can check the order and help you get access to the correct file.

How should I print the project?

The projects are designed for home printing. Use the paper size supplied with the product and print at actual size or 100% unless the project instructions say otherwise.
